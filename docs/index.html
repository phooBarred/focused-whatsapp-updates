Your protection plan

Set weekly schedules or daily viewing allowances, together or separately for the two apps. Choose a waiting period, password, or both before weakening protection. Screen recognition depends on the installed WhatsApp interface and is not guaranteed to work with every update.

Optional Google backup

Sign in with Google to save configuration in Google Drive's hidden app storage. No folder selection is needed. Backups can run on a schedule after you explicitly back up or restore. Protection on/off, active waits, open access windows, daily usage and phone permissions stay on the phone.

Google authorization allows the app to access its own hidden configuration data. It does not request access to all your Drive files. Read the privacy policy for the settings included, storage details and your controls.

Using the app

Enable the Android accessibility service voluntarily using the phone setup checklist. The app examines relevant screen information on the phone to recognize and leave blocked screens. It does not upload screen content or messages.

This is an experimental, free app with limitations. It is not a tamper-proof device administrator. Install updates over the existing app to retain settings; Android still asks you to approve installation. Published release notes describe known issues, including any unresolved Play Protect warnings.
